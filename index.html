Правила сервера

❌
1. Любые читы Запрещено использование сторонних программ, дающих преимущество (X-Ray, Fly, KillAura). Бан перманентный без разбана.
❌
2. Freecam Запрещено использование камеры сквозь блоки для разведки чужих баз и поиска ресурсов.
✅
3. ReplayMod Разрешается использовать только если вы подозреваете игрока в читерстве для записи пруфов. Использовать для поиска баз запрещено.
❌
4. Лаг-машины и Редстоун Запрещено создание механизмов, вызывающих лаги. Запрещено строительство гигантских механизмов редстоуна (орбитальных пушек, TNT-дюперов).
❌
5. Гриферство Запрещена порча чужих построек и воровство из приватных сундуков.
❌
1. Зарплаты нет Администрация — это волонтерская помощь. Вступая в состав, вы не получаете реальных денег или игровой валюты.
✅
2. Реакция на жалобы При поступлении множества жалоб на игрока или при подозрении на читы, модератор обязан провести проверку.
✅
3. Проверка, а не бан Запрещено банить "на горячую руку". Сначала проверьте игрока (спектатор, ReplayMod), и только при доказательствах выдавайте бан.
✅
4. Обязательный Freecam (Модераторы) У модераторов всегда должен быть включен Freecam для оперативной проверки игроков.
✅
5. Адекватность Запрещено использовать админ-команды для личной выгоды, телепортироваться к игрокам без причины или выдавать предметы.
✅
6. Контроль состава Если на админа/модератора много жалоб, верховные администраторы (Владелец) вызовут независимого модератора для проверки его поведения.
