Шпаргалка Администратора

  • Базовые:
    /kick <ник> <причина>, /mute <ник> <время>, /ban <ник>, /unban <ник>, /tempban.
  • Наблюдение:
    /vanish, /invsee <ник>, /enderchest <ник>, /tp, /tphere.
  • Состояние:
    /heal, /feed, /god.
  • WorldGuard:
    //wand, /rg define <имя>, /rg flag <регион> pvp deny, /rg addmember.
  • LuckPerms:
    /lp user <ник> parent set <ранг>, /lp user <ник> permission set <право>.
  • Выдача наборов:
    /kit resources <ник> — набор ресурсов.
  • Разбан:
    /unban <ник> — разбан аккаунта (только если нет грубых нарушений).
